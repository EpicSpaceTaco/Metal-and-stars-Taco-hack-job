# Metal-and-stars-Taco-hack-job
Some assembly required

So here's the thing, it took a fair amount of trial and error to get this working, so bare with me if it doesn't work flawlessly.
As a side note, if the original creator wants this repository taken down, I will comply. It's not my work after all.

Due to file size limits, you need to download both graphic dependencies on the mod portal.

https://mods.factorio.com/mod/metal-and-stars-graphics/downloads

https://mods.factorio.com/mod/metal-and-stars-graphics-2/downloads

However, both need their factorio version changed to 2.1 in the info.json file.
Graphics-2 also needs additional icons that were missing, of which I included in a separate zip file. Just merge the two icon folders together, and you should be right as rain.

Finally, the last hurdle to sort out is the armored biters dependency.

https://mods.factorio.com/mod/ArmouredBiters/downloads

I used this repository to manually patch the original

https://github.com/CybranM/ArmouredBiters/pull/7/changes/dcff665d29d5dba351c370d78d8483cf94a84bdb

And with that, you should be good to go. I hope I didn't miss anything.
